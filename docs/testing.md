# 测试计划与验收记录

## 1. 测试范围

- 登录、会话恢复与退出
- 角色导航和按钮权限
- 员工新增、编辑、删除、搜索、筛选、详情和导出
- 班次分配、重复班次拦截、周切换和智能补齐
- 人员统计、部门概览、库存和补货申请
- 普通员工本人资料与本人班次
- 不同屏幕宽度下的布局

## 2. 自动化测试

运行命令：

```bash
npm test
npm run check
```

最近一次本地结果：

```text
tests 10
pass 10
fail 0
```

覆盖内容：

- HR、Supervisor、Ordinary Employee 权限差异
- 姓名、工号、岗位搜索
- 部门、状态与关键字组合筛选
- 姓名与时薪排序
- 员工必填项、工号唯一性、手机、邮箱与时薪校验
- 同员工同日同班次冲突
- 员工状态与部门统计
- 周一作为每周第一天
- 三个班次名称与时间
- 货币和在职时长格式

## 3. 浏览器验收

| 用例 | 操作 | 预期 | 结果 |
| --- | --- | --- | --- |

| Supervisor 登录 | 切换主管账号 | 导航显示员工查询、排班、统计、库存和记录 | 通过 |
| Supervisor 员工只读 | 打开员工查询 | 无添加、编辑、删除按钮 | 通过 |

## 4. 响应式检查

CSS 断点：

- 1180px：KPI 两列，统计页折行
- 920px：侧栏变为抽屉，顶部显示菜单按钮
- 720px：工具栏、表单与统计图改为单列或两列
- 430px：KPI 与本人班次改为单列
